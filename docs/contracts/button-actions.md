# 名片按鈕與網址契約

本文件定義名片按鈕欄位、格式校驗與儲存規則。

## 欄位

每個按鈕至少包含：

- `label`
- `type`
- `value`
- `color`
- `order`
- `enabled`

建議類型：

- `url`
- `phone`
- `email`
- `line`
- `map`

## 自動正規化

### 電話

輸入電話時，系統應自動轉成：

```text
tel:<phone>
```

允許：

- 台灣手機。
- 市話。
- `+886`、`886`、`86` 等國碼。
- 空格與破折號輸入後正規化。

禁止：

- 無法辨識的電話不得儲存為電話按鈕。

### Email

輸入 email 時，系統應自動轉成：

```text
mailto:<email>
```

禁止：

- 不合法 email 不得儲存。

### 網址

網址必須是：

```text
https://...
http://...
```

允許：

- 一般網站。
- Google Maps。
- LINE 加好友連結。

禁止：

- 空白網址。
- 無協議的網址直接儲存。
- `javascript:`、不明 scheme。

### LINE 連結

允許：

- `https://line.me/...`
- `https://lin.ee/...`

不建議：

- 未確認用途的 LIFF deep link。

## AI 修正

AI 可以協助修正格式，但不得靜默寫入高風險欄位。

允許：

- 提示「偵測到電話，已轉為 tel:」。
- 提示「偵測到 email，已轉為 mailto:」。
- 建議補上 `https://`。

禁止：

- 自動改姓名。
- 自動改 UID。
- 自動改推薦人。
- 自動改 owner。

## 儲存規則

儲存前必須檢查：

- label 不可空白。
- value 不可空白。
- type 與 value 必須一致。
- URL scheme 必須安全。
- 電話與 email 格式必須通過。

若不通過：

- 不得儲存。
- 必須顯示明確錯誤。
- 錯誤訊息應指出是哪個按鈕、哪個欄位。

## 推播與網頁版

推播 Flex 與網頁版必須使用同一份按鈕資料。

禁止：

- 編輯頁顯示一套按鈕，推播用另一套預設按鈕。
- 網頁版缺少按鈕。
- 分享後按鈕變成預設值。

## 測試要求

每次改按鈕功能前，至少檢查：

- 電話自動加 `tel:`。
- email 自動加 `mailto:`。
- 錯誤 URL 不可儲存。
- 編輯頁、推播、網頁版按鈕一致。
- 不同版型不會互相覆蓋按鈕。
