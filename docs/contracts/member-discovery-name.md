# 交流顯示姓名資格

- 2026-10-27 使用者要求「未命名」帳號不要進入交流名單。
- `worker/member-display-name.mjs` 是交流展示用 SQL 規則，並不修改會員名稱或判斷法定姓名。排除空值、純空白，以及精確佔位名稱：未命名、未命名會員、未命名用戶、未命名用户、未命名使用者、unnamed、unknown；比對忽略大小寫、一般及全形空白、換行、tab、NBSP、零寬空白與 BOM。一般中文／英文姓名、暱稱與含「未命名」的正常名稱不以包含字串排除。
- 找會員依最新有效 self_profile，維持姓名→英文姓名→會員姓名的空值 fallback；遇到非空佔位名稱即排除，不以較舊版本或備援姓名掩蓋。公開名冊另檢查真正公開版本姓名→英文姓名，不能用會員姓名或私人版本內容填補。
- SQL 在排序、LIMIT、分頁、隨機選取、配對候選及 presence 篩選前執行；只讀參觀名冊重用同一查詢。補正姓名後下次讀取恢復，不需要管理員手動公開帳號。
- 新建對話使用目前會員的最新有效本人名片姓名；檢查後仍於 INSERT 原子判斷，避免舊 handle 或同時更名繞過。既有對話讀取、未讀數量、封鎖、回覆與管理維持既有規則；不刪除歷史資料。
- 公開動態 list/get 依原作者解析優先序，只檢查目前 users.name，於 LIMIT 前排除；不以貼文標題或私人名片補姓名。ownOnly 管理仍可查看及隱藏／刪除自己的貼文。
- 不改登入、註冊、AI 審核、本人名片歸屬、公開／私人狀態、點數、推播或資料表。
