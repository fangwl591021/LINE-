# 管理員商城店家列表

- 2026-09-23：新增 admin.html「商城店家／商品管理」，重用手機目錄與代上傳模組；獨立 admin/catalog 提供商城展示欄位及上下架管理（詳見 store-admin-catalog.md）。原 stores GET 仍唯讀，原 products POST 仍僅新增。不得用一般 owner API 跨店、變更會員或點數。

- 2026-09-19：合併既有合作店家資料，管理員代建但未綁帳號者可在本表查詢、查看公開頁，並透過「代建／管理合作店家」維護原 partner 記錄。認領需另核實，不在本表變更用戶歸屬。權限驗證及唯讀 API 不變。

- 入口：管理員「設定與參數」的「商城店家列表」，以及商城導覽／本人商城管理的「管理員・店家列表」。
- 僅由有效 LINE 登入及既有後端管理員規則授權。店長、贈點用戶、一般會員及匿名使用者不可查詢。
- LINE profile 驗證採 Cloudflare Workers 支援的 `redirect: manual`；不自動轉送 Bearer token，所有非 2xx（含 3xx）均拒絕授權。不得使用 Workers 不支援的 `redirect: error`。
- 僅讀取店面、負責人名稱、店家聯絡資料與商品數，包含草稿與未符合公開資格的店面；不讀取訂單、付款帳號、點數流水或會員完整個資。
- 可搜尋、依公開狀態篩選、分頁瀏覽。目錄 GET 本身仍唯讀；不授予變更其他店家資料或既有商品的權限。
- 2026-09-19 新增獨立「代上傳商品」入口：僅已驗證管理員可透過 /v1/store-shop/admin/products 對已註冊且有合格負責人的店面新增商品。不得指定 owner_uid、不可代建樣板店商品、不可覆寫既有商品。0040 保存管理員、店家負責人、建立內容與防重送鍵；商品與稽核原子寫入。角色、店面版本與件數限制必須重新核實；正式驗證不建立測試商品。
- 店家介紹圖滿版置中裁切（16:9，桌機最高 360px），列表封面維持 4:3。商品、DM 及上傳原圖仍完整保留。
- 原目錄使用既有資料表；代上傳先套用 0040 migration，再部署 Worker 與前端。正式驗證只做唯讀查詢，不操作會員歸屬、點數或訂單。
