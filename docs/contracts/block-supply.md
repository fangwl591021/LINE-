# 方塊補給站引擎契約（Phase 1）

- 純 JS 決定性模擬，不使用 DOM、網路、timer、音訊、storage 或會員 API。不修改坦克引擎。
- 10 欄 × 16 列，上方兩列為警戒區；落地並消排後仍佔警戒區，或生成位置被擋，即失敗。
- 20ms 固定步進，90 秒遊戲時間；暫停不步進。到達 90 秒時先判定超時，不接受該步新操作。
- 下降間隔 720 / 600 / 480ms（每 30 秒）；最低限制 450ms。按住左右及軟降支援固定步進重複，旋轉/快速落下只在按下邊緣觸發。
- 10 種 3/4/5 格補給造型，固定色彩和符號，呈現層不能只依賴色彩。每袋各形狀一次、固定種子洗牌；每件有 1/5 機率含一格特殊能源。
- 消除 1/2/3/4/5 排給 20/50/90/140/200 能源；連續落地都消排，第二次起每次 +10，未消排重置。每格特殊能源被消除才 +10。
- 遊戲分數 = 能源 × 10，並非會員點數；能源 >=100 即勝利，保留實際超過值。勝敗只觸發一次，終局不再處理輸入。
- 輕量旋轉補位僅水平 0、±1、±2，不穿牆、不向上跳。落地立即固定；硬降不連續吞掉下一件。
- 重開建立新狀態，舊棋盤、連擊、按鍵與亂數不殘留。生命週期 timer/事件清理由 Phase 2 控制器負責，本引擎不建立它們。
- 壓縮重播僅允許整數 mask/步數，限制最大長度、總步數與合理經過時間；重播從種子重算，不接受前端分數。這只是未來後端可重用的純驗證器，尚未接入 API 或發點。
