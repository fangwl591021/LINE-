# LIFF 路由契約

本文件定義 LIFF 與網頁路由的用途。路由必須先分類，再決定能不能寫入資料。

## 路由類型

### View Route

用途：只顯示資料。

允許：

- 讀取名片。
- 顯示網頁版名片。
- 顯示列表。

禁止：

- 寫入使用者資料。
- 改變名片歸屬。
- 改變目前發送版型。

### Edit Route

用途：編輯目前使用者可編輯的資料。

允許：

- 使用 LIFF 身分解析目前 UID。
- 載入目前 UID 的個人名片。
- 儲存按鈕後才寫入資料。

禁止：

- 頁面載入時自動寫入。
- 用 `ref`、`net`、`shareCardId` 覆蓋 owner。
- 抓不到名片時 fallback 到其他人的名片。

### Send Route

用途：在目前聊天室直接發送名片。

允許：

- 在 LINE 聊天室內使用可用 scope 發送訊息。
- 發送目前 UID 的指定名片版本。

禁止：

- 開啟通訊錄選擇器。
- 改變名片資料。

### Share Route

用途：讓使用者選擇好友或群組分享。

允許：

- 使用 `shareTargetPicker`。
- 分享指定的 Flex 名片。

禁止：

- 進入首頁。
- 跑好友檢查或註冊檢查。
- 顯示空白首頁。

### Web Route

用途：在一般瀏覽器顯示完成品名片。

允許：

- 顯示公開可讀的完成品名片。
- 顯示按鈕。
- 提供分享入口。

禁止：

- 呼叫需要 LIFF scope 的 API。
- 要求 LINE token 才能看公開名片。

## 重要參數

### `shareCardId`

用途：分享既有 Flex 名片。

規則：

- 只走分享流程。
- 進入後立即準備分享。
- 不進首頁。
- 不做點數通好友檢查。

### `webCardId`

用途：顯示完成品網頁名片。

規則：

- 可在瀏覽器開啟。
- 不可要求 LIFF token。
- 找不到名片時顯示明確錯誤。

### `share=1`

用途：表示外部分享或網頁展示模式。

規則：

- 不自動寫入資料。
- 不自動更換使用者身分。

### `mode=wysiwyg-card`

用途：進入所見即所得名片編輯器。

規則：

- 必須以目前 LIFF 使用者 UID 查自己的個人名片。
- 可用 `cardId` 指定自己的名片。
- 若 `cardId` 不屬於目前 UID，必須拒絕編輯。

### `ref`

用途：推薦人或分享來源標記。

規則：

- 只能作為歸因。
- 不可作為目前登入 UID。
- 不可覆蓋名片 owner。

### `net`

用途：租戶或網路區域標記。

規則：

- 只能決定查詢範圍或顯示上下文。
- 不可覆蓋身份。

## Scope 錯誤處理

若出現 `The permission is not in LIFF app scope`：

- 顯示可理解錯誤。
- 不得留空白頁。
- 可提供複製網址或返回聊天室入口。
- 不得嘗試以其他使用者資料完成操作。

## 測試要求

每次改動 LIFF 路由前，至少檢查：

- `shareCardId` 只開分享流程。
- `webCardId` 可在瀏覽器看到完整名片與按鈕。
- `mode=wysiwyg-card` 只能編輯自己的名片。
- `ref` 不會改變目前登入者資料。
- token 缺失時，新用戶必要讀取不會被卡死。
