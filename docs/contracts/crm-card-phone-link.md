# CRM 關聯名片補電話

- 只有經 LINE token 驗證的總管可搜尋／確認；一般、店長、贈點、扣點角色及 UID-only 不可操作。
- 管理員搜尋姓名／公司／電話，明確選擇候選名片並再次確認。姓名相同不代表已認領，不得自動配對寫入。
- 只補現有 users 的空白 phone；既有電話（包含操作期间新增）不可覆蓋。預覽與提交名片內容不同需重查。
- 來源是已綁同一 UID 的名片，或未綁人的通訊錄名片；排除占位名片及已綁他人名片。收藏者不等於名片本人。
- 電話去除分隔符、驗證格式；其他會員已使用及保留管理員號碼均阻擋。
- 新增 crm_card_phone_links 保存來源名片、目標會員、電話、操作者、時間；紀錄與補電話在同一 D1 batch 交易。
- 不寫 card_contacts，不改 LINE 綁定、scanner/owner、推薦人、角色、公開池、點數。不要修改 claimed_card_id 或呼叫認領流程。
- 搜尋只讀、最多 25 筆並提示縮小範圍；關聯來源可重新查詢。未操作前不新增任何會員或關聯。
- 正式環境只部署結構與程式，不替截圖中的真人執行關聯。
