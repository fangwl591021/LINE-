# 後台營運統計

後台「營運財務報表」原四張卡為唯讀營運統計，不代表營收、獎金或付款。只允許經新鮮 LINE 身分驗證的既有嚴格總管讀取 `/v1/admin/overview-stats`，不得套用其他管理頁的身分衝突例外。API 只回四項非負整數，禁止回傳會員名單或寫入資料，禁止快取回應。

- 會員資料筆數：`users` 所有資料列，包含自動建檔及尚未完成資料；不是已完成註冊的人數。
- 名片資料筆數：`card_contacts` 所有資料列，包含已合併紀錄。
- 已上架活動主項：`status='上架'`，不計系列子場次。
- 有效報名紀錄：`registrants` 排除 `cancelled`；不代表不重複人數。

讀取失敗或權限無法確認時顯示未能讀取及重試，不以 0 冒充資料；已載入的 CRM、名片分頁不能覆寫這些全站統計。登出、切換身分或失去權限時清除舊顯示。不可啟用舊 `getAdminStats` 作為上述路由別名：手機管理頁期待其他營收欄位，缺值會被誤顯為零。
