# 後台營運統計

後台「營運財務報表」原四張卡為唯讀營運統計，不代表營收、獎金或付款。只允許經新鮮 LINE 身分驗證的既有嚴格總管讀取 `/v1/admin/overview-stats`，不得套用其他管理頁的身分衝突例外。API 只回四項非負整數，禁止回傳會員名單或寫入資料，禁止快取回應。

- 會員資料筆數：`users` 所有資料列，包含自動建檔及尚未完成資料；不是已完成註冊的人數。
- 名片資料筆數：`card_contacts` 所有資料列，包含已合併紀錄。
- 已上架活動主項：`status='上架'`，不計系列子場次。
- 有效報名紀錄：`registrants` 排除 `cancelled`；不代表不重複人數。

讀取失敗或權限無法確認時顯示未能讀取及重試，不以 0 冒充資料；已載入的 CRM、名片分頁不能覆寫這些全站統計。登出、切換身分或失去權限時清除舊顯示。不可啟用舊 `getAdminStats` 作為上述路由別名：手機管理頁期待其他營收欄位，缺值會被誤顯為零。

## 營運財務報表（2026-11-17）

- 新增獨立唯讀 `GET /v1/admin/finance-report`，採現有獎金報表相同的總管身分驗證及既有個別身分例外；讀取前後均重新驗證。原四項統計路由的嚴格權限不變。
- 月份篩選：年費已收依 `paid_at`，待收依 `created_at`；已確認業績依確認紀錄的業績月，無業績月時依確認時間；傭金依既有業績歸屬月（歷史人工補登使用經驗證的歷史月）；銀行匯款與舊月結依各自付款日。所有日期採台北時間。
- 年費只列台幣年費與續約；店家商城已收取 `received_cents`，買家回報與待付款分開，屬店家收款，不能併入平台年費或稱為平台營收。未記錄收款日期、異常月份及非台幣另警示。已取消、其他來源及平台外收支不算入；不得宣稱已扣除退款或完整損益。
- 已確認業績僅算已付款且有成交確認的訂單；傭金依原始流水狀態分列，不把待核對當成已付款。已登錄銀行付款與舊月結已付標記分開，不能相加聲稱實際匯款。
- 年費訂單分頁；CSV 匯出全部符合月份的年費訂單與彙總，包含待核對提示，跨頁核對筆數及彙總一致；上限 5,000 筆。試算、報表、匯出均不寫入資料或發起交易。
- 每次報表相關查詢使用一筆 D1 batch 讀取一致快照；查不到完整結果顯示錯誤，不能以零冒充。切換登入或總管權限時清空畫面；匯出期間不允許更動篩選條件。
