# 活動／課程 QR 核銷（2026-10-09）

- 會員活動與官方活動／課程保留原資料、報名與可見範圍，非商城點數。公開不授予其他店主名單或核銷權。
- QR 在瀏覽器用既有本機 qrcode-generator 產生，不依賴未載入全域，也不把票證／報名 ID 送第三方 QR 服務。
- 會員活動沿用隨機、雜湊、五分鐘票證、重發失效、本場主辦與起迄期間；不修改其核銷 API 或點數。
- 官方 QR 保留既有 verifyCheckin／checkinRowId／registrationId LIFF 相容，改呼叫 manager action redeemActivityCheckin。資料库只把 checked_in 設為 1；重送／重掃保留首次時間，回傳 duplicate 與 checkedIn=true，永不取消簽到。
- 手動 toggleCheckin 仍供明確簽到／取消簽到，送出鎖定、不自動重試。新舊核銷 action 均需已驗證 token 與本場管理權，解析真實報名 activity_id，不相信 payload role/network/活動編號；錯場、已取消、缺失拒絕，不退回未受保護的 GAS。
- 官方 QR 只核銷上架活動及有效報名；不新增時段／NFC 贈點規則。既有手動管理歷史名單保留。多梯次 QR 保留確切報名ID；父活動掃描器可核銷合法同網子梯次，不可跨場。
- 原子 UPDATE 同時核對報名有效、活動歸屬及已讀狀態；並行／歸屬變更不取消簽到或繞過權限。回應不確定時提示核對最新名單，不宣告成功。
- 手機「管理核銷 → 本場核銷」與 admin「報名名單」均有「開啟核銷掃描器」，共用專用活動掃描 UI。只接收平台／正確 LIFF 的核銷 URL，必須匹配所選活動，不接受名片、商城點數或任意 URL。
- 使用者按開始才請求相機，畫面提供相機、選 QR 圖片與貼上 QR 三種方式；影像只在本機解碼，不上傳。QR 成功／重複／錯誤有可讀反饋，返回／關閉始終可用；離頁、隱藏、切帳號、切換本場釋放鏡頭與舊回應。
- 核銷後重新讀取同一活動名單；手動刷新保留 activityId，取消報名不能簽到，取消資料保留。scanner 與管理 UI 不新增付款、贈點、扣點、通知或其他資料寫入。
- 上線必須驗證兩種建立方式與活動／課程類別；Node SQL、瀏覽器和 Workers/D1 runtime 證據分開報告；實機 LINE OAuth／相機不能以模擬結果冒充。
