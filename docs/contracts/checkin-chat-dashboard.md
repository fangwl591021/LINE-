# 會員打卡聊天室儀表板

- LINE 訊息是單一 Flex carousel；頁面 2–12、相同寬度、JSON 不超過 LINE 上限。母站原文字與其 replyToken 保留原流程，補送仍只有一則，不因頁數增加推播次數。
- 會員購物金固定為首頁，數字與查詢時間只取目前既有錢包查詢，不可在編輯器輸入或推算。無資料顯示無法取得，不以零或固定加點金額代替；不自稱已打卡成功或已入帳。
- 管理員編輯文字、主題色、說明頁 HTTPS 圖片、頁序與按鈕；按鈕目的地限定既有商城及明細，沿用原 LIFF 登入與已驗證進入報告，不接新的送字、任意外鏈或贈扣點動作。結果提醒與點擊告知固定保留。
- 草稿與已發布版本分開。只有發布的配置影響之後的卡片；儲存／發布均使用版本 CAS 和請求識別，不覆蓋並行編輯。重試不能新增另一版或恢復舊內容。預覽只編譯示意資料，不查錢包、不送 LINE、不計點擊。
- API 每次以 LINE token 及既有 canonical/hard-admin 權限校驗；前端自稱的角色、UID、tenant 或資料庫 alias 不得擴權。寫入前再核對當下權限；無權、格式失敗及版本衝突不得寫入。
- 新資料僅存在獨立模板與卡片快照表。送出前保存套用版本、配置與完整 Flex，之後不得覆寫。歷史 CRM 使用當次快照，配置更新不改舊訊息；舊單頁卡無快照時沿用原摘要，並標示 API 接受不等於送達／已讀。
- 編輯器以穩定頁面／按鈕識別維持選取，提供頁面清單、可點選即時預覽與屬性編輯。切換頁籤保留草稿；版本衝突保留本地內容；身份／權限變更與遲到回應不能套進新會話。預覽按鈕只選取，不開商城或計點擊。
- 不變更打卡、母站贈點與點數轉換、原錢包讀取介面、事件日去重、LINE retry key、未知送出結果不重試等原契約。

## 勾選店家已上架商品（2026-10-25）

- 保留自訂頁，管理員可從公開店家商品勾選商品頁；勾選只改卡片草稿，不修改商品上下架、庫存或交易設定。總頁數仍包含首頁與自訂頁，最多 12 頁。
- 商品頁設定只存 page ID、shopId、productId；名稱、圖片、價格、購買方式與折抵資格只由現行公開 catalog 解析。商品及店家均須 active 且店主符合既有公開角色資格；僅展示店家不能被標為可交易／可折抵。清單不能讀私人聯絡、銀行、訂單或會員身分。
- 草稿保留失效商品參照並明確顯示不可用，發布前核對當下公開資格與版本。發送前再查一次，並以 SQL 條件核對來源版本；若已下架或無法安全顯示，在原位置顯示中性說明，不改選其他商品，也不丟失購物金及自訂頁。
- 產品快照保存實際發送當時的解析內容；改價、下架或後續編輯不能重繪舊卡。商品額外來源資料與點擊放在獨立新表，舊快照及商城／明細點擊紀錄維持原樣。
- 商品按鈕固定查看所選商品詳情；URI 只帶卡片與頁面識別，不帶任意目的 URL、商品、店家、UID 或角色。登入後伺服器由發送快照解出商品並重核目前公開資格，再交前端進入正確的公開商品詳情，不進掃碼核銷或改選第一件商品。
- 點擊使用實際登入開啟者，依卡片／頁面／人／分鐘去重，與原商城／明細報告一起查詢。預覽、GET、未登入、無效頁、未發送或已下架目標不得記成有效商品進入；匿名不能讀模板或報表。
