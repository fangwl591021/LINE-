# 交流專區上方頁籤

- 同一交流專區上方固定「我的聊天／找會員／公開動態／我的貼文」四個頁籤，只有內容區捲動；選中狀態必須對應實際內容。延續預設公開動態。
- 刊登說明、貼文數及「新增自我宣傳」入口只在「我的貼文」顯示；公開動態直接顯示貼文列表，不重複刊登區塊，亦不改變公開貼文資料或本人管理權限。
- 私訊沿用既有模組，僅增加容器內呈現方式，不再疊加第二組主頁籤。獨立開啟與通知深連結仍可用；對話內返回回到我的聊天。
- 「找會員」只顯示文字／業種搜尋與會員列表，不重複接受新聯絡、LINE通知、LINE 加好友資料編輯及通知說明；這些設定保留於「我的聊天」。切換顯示不可寫入或重設偏好資料。
- 「我的聊天」以精簡頁首與聊天列表為主；聯絡、通知與 LINE 加好友設定集中到預設收合的「設定」。展開可捲動與收合，鍵盤可操作；返回列表或重新開啟時收合，不重設偏好。聊天列維持既有姓名、訊息摘要、時間、未讀數及原排序，其他頁籤樣式不變。
- 私訊重用同一顆重新整理按鈕：我的聊天位於設定左側、找會員位於業種篩選旁、個別對話位於返回列。收合／捲動時仍可操作；按下只沿用既有重新讀取／登入重試，不切換設定開合，不新增重複按鈕。
- 窄螢幕與長姓名不得擠出重新整理、返回、關閉或傳送按鈕；對方完整姓名保留於文字與 title。公開動態／我的貼文沿用原捲動容器，關閉及管理操作必須可達，不新增資料操作。
- 切換頁籤或關閉交流專區須停止私訊輪詢、取消未完成讀取並關閉子 POP；載入較慢的 import／API 回應不可在另一頁籤或關閉後重新顯示。
- 未確認送出的私訊切換時保留既有確認提示。本人貼文 ownOnly／隱藏／刪除、配對、優惠券、LINE 加好友與通知設定均沿用原權限及服務。
- 本次純前端；不更動登入、Worker、資料庫、點數及通知排程，不新增群聊或好友系統。
- 手機／桌面驗證四頁籤、捲動固定、切換與返回、關閉停止輪詢、延迟回應、通知入口、POP 及原貼文隱藏管理。

## 加入編號顯示 2026-10-25

- 「找會員」在姓名與公司／職稱下顯示既有公開會員編號，標示「加入編號」。API只新增canonical users.member_number 對應的memberNumber；缺漏或格式錯誤顯示空值，不從UID、姓名、電話或名片列推算。
- 編號是識別用途。歷史日期未知的舊會員以補編日配置，不能直接從前八碼推算加入資歷。目錄不增加加入日期／日期來源、LINE UID、電話或其他私人欄位。
- 原搜尋、業種、配對排序、停止新聯絡、封鎖及canonical身分篩選保持；讀取目錄不配號、不改會員資料或偏好。

## 實際 LINE 頭貼 2026-10-25

- 「找會員」只增加實際 LINE 頭貼 avatarUrl，來源為伺服器驗證後的 LINE profile 或既有 OA 使用者頭貼；不拿自訂上傳頭像或名片封面替代。
- 僅為通過原目錄權限篩選的當頁會員取得頭貼；伺服器內部 UID 不回傳。會員、名片、身分連結、偏好、點數及 OA 私訊紀錄不修改，不新增 schema。
- 頭貼使用獨立 MEMBER_CHAT_LINE_AVATAR_ KV 快取；已驗證的無頭貼狀態不得被舊 OA 圖覆蓋。快取、OA 讀取及有界 LINE profile 補查失敗均不阻擋名單。
- 只有找會員列顯示圖片；載入前、無安全 HTTPS 網址或圖片載入失敗時顯示姓名字首。我的聊天及其他頁籤保持。
- 搜尋、業種、配對、排序、分頁、停止新聯絡、封鎖與 canonical 會員解析照舊。

## 公開動態作者頭貼 2026-10-26

- 公開動態、我的貼文及貼文詳情的作者頭貼沿用既有 LINE 頭貼 helper，僅查詢原權限篩選後當頁作者；不以名片封面替代，名片詳情封面照舊。
- 內部作者 LINE ID 不回傳；當頁作者去重，依既有 30 人上限分批取得。無頭貼或服務失敗不阻擋貼文，圖片載入前／失敗時顯示姓名字首。
- 不改貼文、會員、名片、點數、按讚、權限或訊息資料；只允許既有獨立頭貼快取的顯示用途寫入。
