# 交流專區上方頁籤

- 同一交流專區上方固定「我的聊天／找會員／公開動態／我的貼文」四個頁籤，只有內容區捲動；選中狀態必須對應實際內容。延續預設公開動態。
- 刊登說明、貼文數及「新增自我宣傳」入口只在「我的貼文」顯示；公開動態直接顯示貼文列表，不重複刊登區塊，亦不改變公開貼文資料或本人管理權限。
- 私訊沿用既有模組，僅增加容器內呈現方式，不再疊加第二組主頁籤。獨立開啟與通知深連結仍可用；對話內返回回到我的聊天。
- 「找會員」只顯示文字／業種搜尋與會員列表，不重複接受新聯絡、LINE通知、LINE 加好友資料編輯及通知說明；這些設定保留於「我的聊天」。切換顯示不可寫入或重設偏好資料。
- 「我的聊天」以精簡頁首與聊天列表為主；聯絡、通知與 LINE 加好友設定集中到預設收合的「設定」。展開可捲動與收合，鍵盤可操作；返回列表或重新開啟時收合，不重設偏好。聊天列維持既有姓名、訊息摘要、時間、未讀數及原排序，其他頁籤樣式不變。
- 切換頁籤或關閉交流專區須停止私訊輪詢、取消未完成讀取並關閉子 POP；載入較慢的 import／API 回應不可在另一頁籤或關閉後重新顯示。
- 未確認送出的私訊切換時保留既有確認提示。本人貼文 ownOnly／隱藏／刪除、配對、優惠券、LINE 加好友與通知設定均沿用原權限及服務。
- 本次純前端；不更動登入、Worker、資料庫、點數及通知排程，不新增群聊或好友系統。
- 手機／桌面驗證四頁籤、捲動固定、切換與返回、關閉停止輪詢、延迟回應、通知入口、POP 及原貼文隱藏管理。
