# 收藏名片配對恢復

- 已有ai/rules有效分數及理由是會員資料，包含0%；不得因重試、需求或名片版本改動而重算或覆寫。
- 僅尚無有效分數的已授權本人收藏名片可補算；沿用原actor授權、收藏歸屬及既有核准的商務資料投影，不送姓名、電話、敏感特質。
- 無效補算紀錄須記錄無PII的失敗分類與retryAt，不保存provider原始錯誤或金鑰。quota為等待額度，provider/timeout/invalidresponse為短退避，不製造0%替代失敗。
- quota重試不得早於既有UTC日額度重置（台北08:00），不得清除正式額度。交流目錄自動配對子額度不超過12批，仍扣既有共享20次每日上限，為收藏／手動保留空間；不擴張總額度。
- 可見名單的失敗／processing到期會重新讀取伺服器狀態，再決定補算；回到列表或回前景不能永遠命中過期失敗快取。重試有限次且有限頻率，避免失敗耗盡每日額度。
- 換owner/token、離頁、關閉、隱藏頁面時停止自動處理；遲到回應不能更新另一身分或已離開的名單。手動重新整理不能繞過伺服器退避／額度。
- 完成分數、最新收藏與配對排序、點選理由、名片詳情與既有歸屬可見規則保持不變。
