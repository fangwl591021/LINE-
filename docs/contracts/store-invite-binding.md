# 店家邀約登入歸屬

## 範圍

店家商城邀約帶有指定店面與邀請人。匿名瀏覽仍無須登入、不寫入歸屬；經 LINE 登入且確認是有效店家邀約後，才呼叫 `POST /v1/store-shop/invite/accept`。普通商城連結沒有邀請人時，不自動綁定。

## 寫入邊界

- 後端以 LINE access token 確認操作者，不接受 body 的 UID、角色或 network 作為權限來源。
- 邀請人必須符合已公開店面的實際擁有人；歸屬網由後端會員資料決定。
- 已有推薦人、已指定非預設歸屬網或管理角色的會員保持原歸屬，不被新邀約覆蓋。
- 未有歸屬者只建立必要會員識別及推薦人／歸屬網；姓名、電話、生日、個資同意及收件資料不代填。
- 寫入需具備併發保護：重複登入與兩個店家邀約同時到達，不改寫第一個成功固定的歸屬。
- 身分別名不明確時拒絕寫入，不建立第二個帳號；本人邀請本人不新增歸屬。
- 不呼叫完整註冊、母站同步、贈扣點、名片建立或公開、訂單及支付流程。

## 前端

後端確認完成後，使用回傳的會員資料繼續顯示原店。歸屬失敗或回應不完整時，顯示重新連線提示，不假稱已完成。網購人與收件資料維持原本的獨立表單。

## 發布

沿用現有 `users` 與 `user_identity_links`，不需要新增 migration。必須先部署支援此端點的 Worker，再發布新版前端。正式站未經授權，不以真實帳號做綁定測試；本機以 SQLite 與模擬 LINE 驗證測試。
