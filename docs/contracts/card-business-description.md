# 名片業務說明

- 優先寫具體產品／服務，再寫有來源的特色、用途與合作方向。繁體中文4–5行短句、約60–120字（最多140字），保留真正換行及完整產品名，不硬切字數；可針對已確認業務美化情境、加入自然邀請，不重述姓名職稱或拿電話Email洽詢湊內容。沒有通過行數／長度的搜尋結果不能假稱成功美化，不截掉長文或補空話。
- 先自動用名片公司、網址、公開社群、姓名與電話核對同一人／公司，再從可讀來源整理實際業務。公司名、職稱、照片、登記營業項目、網址字樣本身不能證明業務；不得猜測專長／市場地位／成效／證照／客戶／療效／投資收益。
- OCR仍單次模型呼叫，同時定位與辨識正反面。serviceDescription仍是原文擷取，profileDescription才是整理文案；沒有業務時只保留簡短身分，不虛構業務，也不加制式聯絡段落。
- 既有generateCardCopy action、token權限、50次額度及business_intent分支保留。搜尋僅傳必要身分線索與業務文字，電話僅作公開業務交叉核對；不送UID、Email、生日、財富健康／私有標籤、照片或按鈕。沿用平台key與OPENAI_MODEL，搜尋不降級成無搜尋的純文字猜測。
- 重用店家搜尋的HTTPS／DNS／轉址／大小限制、同公司判定、實際來源摘錄核對與登記項目排除。名片獨立card-business:額度50次／日、15秒間隔；不動店家原本20次額度。失效官網改找其他公開來源；不可用／同名不明時保留原文，不存制式本機版。來源連結及索引未直讀警告在草稿中顯示。
- 編輯器AI草稿僅預覽，使用者明確帶入後還須套用／儲存。失敗、取消、改欄位、切名片／身分或過期回應不得覆蓋；拒絕重複點擊，不自動分享／公開。
- 所有正式舊名片保持原樣。既有寫入權限、認領、審核與四版隔離不變。
- 名片編輯畫布於說明下方提供「AI 美化介紹 · 4～5 行」入口，點擊才開始搜尋；本人與可編輯收藏名片使用目前卡片，不切換身分。OCR 有服務文字時套用同一文案規則並保留換行；資訊不足仍保留辨識資料供核對，不自動宣稱完成業務美化。
- 名片可能有OCR錯字或不同品牌：僅名片模式可用來源同段的品牌＋電話＋完整地址／完整姓名作雙線索橋接，不改店家原有公司／品牌判定。品牌業務摘錄須含品牌名，不能借用通路同頁其他商家的業務；僅單電話／單地址／模型宣稱不可通過。原公司名稱不自動改動，明示請核對。
