# 人脈島與主頁私訊未讀提示

- 商務交流島的使用者可見名稱改為「人脈島」，包括首頁、島內標題、無障礙名稱及載入／失敗提示；內部路由、檔名、API、ID與商城大富翁維持。
- 人脈島的「開始交流」仍開啟既有會員私訊；主頁交流專區紅色徽章統計目前會員收到且尚未讀取的訊息數量，不是聊天數、不含站內收件夾、本人發出的訊息或已讀訊息。
- GET /v1/member-chat/unread 不接受查詢條件、UID、body 或其他方法。每次沿用既有 LINE token、canonical 身分、交流權限與本人名片資格；跨所有聊天單次 COUNT，與既有聊天名單的 peer-user 可見範圍相同。只回 {success:true,unread:非負安全整數}，不回姓名、聊天識別、內容或私有欄位。零寫入、零推播。
- 徽章 0 隱藏，1–99 顯示數字，100 以上顯示 99+；按鈕無障礙名稱提供完整數量。主頁可見、交流入口已依原資格顯示且已登入才讀取；每輪完成後約20秒更新，回主頁、回前景及 BFCache 恢復重新確認。
- 離開主頁、背景及 pagehide 中止請求／輪詢；低成本本機會話檢查不作網路請求。owner、token、base或DOM改變即清除舊數字並讓舊回應失效；同時最多一個請求，已讀後的強制更新可合併排下一次。
- 只有既有聊天讀取成功標記其已顯示游標後，才要求徽章重查；徽章自身不開對話、不標已讀、不自動發訊，也不改通知偏好或入口資格。
- 失敗不假造0；同會話可保留最後確認值並標示暫時過期，401/403（包括非JSON回覆）清除徽章並停止直到重新確認會話／入口。未登入、權限不足、跨帳號或遲到回應不顯示他人數字。不把數字或token寫入localStorage。
