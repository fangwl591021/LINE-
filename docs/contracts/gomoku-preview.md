# 喵喵五子棋：本機預覽契約

- 第一階段為原創可愛風可玩預覽；獨立 `preview-gomoku` 持續不登入、不發點、不讀會員、不請求外部 AI。2026-09-22 第二階段新增遊戲館整合，規則見 `game-center.md`；仍未部署。
- 15×15 交叉點；玩家黑棋先手、電腦白棋；自由規則，連續五顆以上勝，四方向皆驗證，滿盤無勝則和局。不使用禁手。
- 操作先選落點再確認，支援鍵盤與觸控；思考中/已結束不得落子，已有棋子不能覆寫。
- 三級本機搜尋：入門、標準、進階（非職業棋力保證）。各級會完成立即勝局並攔截對手立即勝局。
- 練習可悔棋、提示、重開；悔棋回到玩家回合；重開/切難度/離開必須取消舊 AI 回覆。
- 音訊必須由使用者操作開始；音訊失敗不阻斷遊戲，可關閉音效和音樂；背景/離開停止播放。
- 引擎為無 DOM 純模組，第二階段加入後端固定難度、session seed 重播；獨立預覽仍不呼叫該服務。
- 新原創插畫用於封面，棋盤/棋子由 Canvas 繪製，不使用參考遊戲原有角色、名稱或素材。
- 2026-09-22 棋子外觀改為原創橘貓（玩家）與灰貓（電腦），仍是相同的 1/2 棋盤值；半透明預覽與最後一步外圈保留，不改判勝或獎勵。
- 單元測試與手機/桌面本機瀏覽器驗收；修改前後完整 guard 均須通過。
