# 店家商城第一階段

## 2026-09-10 商品共用點數入口（本機實作，尚未部署）

- 商品右下角 QR 僅包含 LIFF 商品 ID；登入後驗證本人店面，再掃顧客點數 QR、手動輸入與確認折抵。
- 商品折抵使用既有 gift_money 母站帳本及共用收銀防重送日誌；不轉點、不結算、不建立第二個錢包。
- 每次送出重查商品與店面版本、上架狀態、店家角色、價格與上限。不折抵商品不能扣抵；目前收銀只支援整數元價格，一次一件。
- 商品變更或下架拒絕舊畫面交易；超額拒絕；母站結果不明保留交易及鎖定供人工核對，不自動重扣或退點。
- 以下第一階段描述保留為歷史；交易新增規則以上述及 store-point-cashier-protected-flow 最新條款為準。

- 依福委會店家/商品/公開店面/核銷分離架構；取代舊平台限定上架方向，不搬正式資料或福委帳密。
- 店家 store/tenant/店長/租戶及既有 admin/總管可管理本人店面；admin 不可跨店。每次寫入即時驗證 LINE token，再查 users，前端角色/UID 不可信。
- 店面與商品獨立 store_shop_* 表；owner 唯一、不公開，版本不符回 409，封存不硬刪。
- GET /v1/store-shop 公開目錄及 ?shop=ID 店面；GET /manage 本人資料；POST /store、/product 本人儲存。有界 JSON、有界列表、安全圖片網址、公開只看 active。
- 第一階段僅設定商品折抵政策 none/fixed/percent/full，不扣點、不下單、不核銷、不收費、不轉點、不結算。
- 第二階段才接共用點數：會員確認、權威餘額、冪等、防併發重扣、跨服務補償、取消退點。分店/有效期與交易 UI 留下一階段。
- 只替換精選功能第三顆點數查詢；錢包及外部折抵店家入口不變。商城按需載入，公開 store-shop.html 不初始化 LIFF。
- 不變：名片 ownership、年費 orders、點數權威、既有收銀、身份映射。舊 platform-shop 只作相容保留，不發展第二套交易流程。
- 驗收：未登入/非店家/跨店拒絕寫入；下架不公開；版本衝突不覆寫；價格/URL/政策驗證；XSS、防重送、無點數呼叫。

## 2026-09-10 商品分類（待發布）

- 商品獨立 category 欄位：食、宿、遊、購、行、服務、製造；空值表示未分類。新增／編輯使用下拉選單，舊商品不自動猜分類。
- 店家列表標籤只篩選有該類已上架商品的公開店面，與搜尋及游標分頁併用；店內與管理商品標籤原地篩選，保留未儲存表單。
- 後端白名單及 SQL CHECK 驗證；舊客戶端更新未傳 category 時保留原分類，原權限及版本檢查不變。
- 部署順序：先套用 0031_store_product_category.sql，再 Worker，最後前端。只新增分類欄位和索引，不更動點數、交易、商品 ID、價格及所有權。

## 2026-09-10 圖片

- 公開列表/店面/商品圖片全卡寬且等比完整呈現，不固定高度裁切。
- 店面與商品表單提供直接上傳按鈕，使用既有 uploadImageToR2；圖片網址收在進階選項。
- 只支援 JPEG/PNG/WebP，來源最大 10MB/4000 萬像素；等比縮至最長邊 1600px JPEG，輸出限 4MB，不裁切。
- 上傳前確認仍可管理自己的商城；進行中禁止送出或切換；失敗保留原 URL 與表單，取消選檔不寫入。
- 上傳的素材可公開存取；選檔前說明，且只有儲存店面/商品才改發布內容。不刪除既有素材。
