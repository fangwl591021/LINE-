# 店家商城第一階段

## 業績購買者與緊湊版面（待發布）

- 明細依交易 customer_id 對應 users 的 line_id／point_line_id／legacy_line_id／row_id；唯一一筆才顯示目前會員姓名。不用收藏名片、creator 或電話猜人，避免收藏者被誤當購買者。
- 姓名未提供或多重對應明示，附 SHA-256 店內顧客辨識碼（owner + customer，前 12 hex），同店可區分／查找，跨店碼不同；不輸出完整 UID、電話、QR 或原始紀錄。辨識碼非認證憑證。
- 姓名查詢只作用於本頁交易，不改總計、分頁、點數或交易；多筆身份匹配不可讓業績加倍。
- 統計縮為單一緊湊 2×2 區塊，交易改成連續列表；商品／時間、購買者、金額／折抵／應收直接顯示，編號与詳細時間收合。

## 2026-09-10 商城業績查詢（本機實作，待發布）

- 管理畫面「業績查詢」按需載入；今日、近 7 天、本月、自訂起訖最多 366 天，台灣時區按交易成功確認時間計算。
- GET /v1/store-shop/sales?start=YYYY-MM-DD&end=YYYY-MM-DD&page=0：即時驗證 LINE token 與店家角色，只查 authenticated actor 與本人店面雙重範圍；不接受傳入 owner UID 擴權。每頁 20 筆，整段期間總計不隨分頁改變。
- 只統計 store_cashier_requests 的 succeeded、redeem 且有本人商品的有效交易，金額取交易紀錄，不取商品現價；失敗／待核對／贈點／一般收銀不算入。封存或下架不抹掉歷史。
- 顯示成功筆數、商品金額、折抵點數、折抵後應收、交易時間與編號；不輸出顧客 UID、QR 憑證、原始 JSON。應收不等於已收現金；商品名稱是目前名稱，沒有完整保存的舊交易不補造。
- 唯讀查詢，不動母站點數、交易狀態、收銀防重送及身分映射。查詢失敗明確顯示錯誤，不顯示假零；離開畫面後忽略遲到結果。
- 0033 僅增加 actor/status/date 查詢索引；發布時套用索引後部署 Worker 與前端。驗證涵蓋權限、日期邊界、分頁、封存／改價及手機 320/390px。

## 2026-09-10 商品共用點數入口（本機實作，尚未部署）

- 商品右下角 QR 僅包含 LIFF 商品 ID；登入後驗證本人店面，再掃顧客點數 QR、手動輸入與確認折抵。
- 商品折抵使用既有 gift_money 母站帳本及共用收銀防重送日誌；不轉點、不結算、不建立第二個錢包。
- 每次送出重查商品與店面版本、上架狀態、店家角色、價格與上限。不折抵商品不能扣抵；目前收銀只支援整數元價格，一次一件。
- 商品變更或下架拒絕舊畫面交易；超額拒絕；母站結果不明保留交易及鎖定供人工核對，不自動重扣或退點。
- 以下第一階段描述保留為歷史；交易新增規則以上述及 store-point-cashier-protected-flow 最新條款為準。

- 依福委會店家/商品/公開店面/核銷分離架構；取代舊平台限定上架方向，不搬正式資料或福委帳密。
- 2026-09-11 條件更新：一般會員 user/用戶可建立本人店面、使用 DM 辨識並管理一件未封存商品（草稿計入，封存後可替換）；店長 store/店長及管理員 admin/總管不限件數。tenant/租戶及未知角色仍不開放管理，admin 不可跨店。每次操作即時驗證 LINE token，再查 users，前端角色/UID 不可信。
- 名額在 INSERT/UPDATE 的同一 SQL 內核對角色及未封存商品，不能以連續或並行請求繞過。角色降級不刪除歷史商品，允許封存以恢復名額。管理及公開商品以 product_after 游標每頁 100 件，回傳 product_next；管理另回 product_count、product_limit（null 表示不限），100 不是商品總量上限。
- 本次只開放一般會員的目錄展示與 DM：其商品限 in_store、redeem_type=none；收款設定、業績、商家訂單、商品 QR 與扣點仍限原店長/管理員權限。公開 merchant_enabled 控制是否呈現可用的交易入口，伺服器仍獨立驗權。顧客瀏覽、購買與本人訂單查詢保留。
- 店面與商品獨立 store_shop_* 表；owner 唯一、不公開，版本不符回 409，封存不硬刪。
- GET /v1/store-shop 公開目錄及 ?shop=ID 店面；GET /manage 本人資料；POST /store、/product 本人儲存。有界 JSON、有界列表、安全圖片網址、公開只看 active。
- 第一階段僅設定商品折抵政策 none/fixed/percent/full，不扣點、不下單、不核銷、不收費、不轉點、不結算。
- 第二階段才接共用點數：會員確認、權威餘額、冪等、防併發重扣、跨服務補償、取消退點。分店/有效期與交易 UI 留下一階段。
- 只替換精選功能第三顆點數查詢；錢包及外部折抵店家入口不變。商城按需載入，公開 store-shop.html 不初始化 LIFF。
- 不變：名片 ownership、年費 orders、點數權威、既有收銀、身份映射。舊 platform-shop 只作相容保留，不發展第二套交易流程。
- 驗收：未登入/非店家/跨店拒絕寫入；下架不公開；版本衝突不覆寫；價格/URL/政策驗證；XSS、防重送、無點數呼叫。

## 2026-09-10 本人商品動態 QR（待發布）

- 商品右下角改為「出示本人 QR」，只有會員點選才向後端產碼，不因商品列表載入而建立大量憑證。公開頁面引導 LINE 登入，接續選定商品。
- QR 不含 UID；5 分鐘短效、更新舊碼失效、限本商品店家查驗。店家扫碼後自動帶入商品、會員與點數餘額，無須手輸 UID，仍須核對並確認折抵點數。
- 發布須先套用 0032，再 Worker 與前端；安全細節見 store-point-cashier-protected-flow.md。

## 2026-09-10 商品分類

- 商品獨立 category 欄位：食、宿、遊、購、行、服務、製造；空值表示未分類。新增／編輯使用下拉選單，舊商品不自動猜分類。
- 店家列表標籤只篩選有該類已上架商品的公開店面，與搜尋及游標分頁併用；店內與管理商品標籤原地篩選，保留未儲存表單。
- 後端白名單及 SQL CHECK 驗證；舊客戶端更新未傳 category 時保留原分類，原權限及版本檢查不變。
- 部署順序：先套用 0031_store_product_category.sql，再 Worker，最後前端。只新增分類欄位和索引，不更動點數、交易、商品 ID、價格及所有權。

## 2026-09-11 商品銷售方式

- 每件商品新增 purchase_mode：in_store（限店內）、online（網購），新增與編輯皆用同一下拉選單，列表及詳情顯示標籤。
- 0035_store_product_purchase_mode.sql 僅加欄位及 CHECK；舊商品預設限店內，價格、點數規則、ID、所有權和歷史不變。店家明確改為網購才可線上下單。
- 更新未傳 purchase_mode 的舊客戶端保留目前設定；非法值拒絕。既有 owner、version 和重送保護維持。
- 公開網購入口只供有 online 商品的店面；網購清單不含限店內商品。後端報價與原子建單也檢查 active + online，防止繞過前端或建單競態。
- 不修改既有現場 QR／點數扣抵後端，也不自動開啟全站或各店的網購收款設定。
- 發布順序：經授權後先套用 0035，再 Worker，最後前端；不能只部署前端。回退程式時保留新增欄位及商品設定，不刪資料。

## 2026-09-10 圖片

- 公開列表/店面/商品圖片全卡寬且等比完整呈現，不固定高度裁切。
- 店面與商品表單提供直接上傳按鈕，使用既有 uploadImageToR2；圖片網址收在進階選項。
