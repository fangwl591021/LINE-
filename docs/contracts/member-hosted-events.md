# 會員辦活動（VEO 模式）

- 新增行程勾選「辦活動」後先核對活動標題、內容、起迄、地點、人數、截止及收費說明；確認發布才寫入。取消草稿不寫入。
- 一筆會員活動同時投影到本人行事曆、活動列表及報名紀錄；不複製為官方活動或梯次，不更動私人 personal_tasks。
- 已驗證 LINE token 經既有 canonical identity 取得 users.row_id；不信任 URL、payload、快取中的 UID、角色或推薦人。一般註冊會員即可辦／報名，不要求本人名片。
- 每人最多一場未結束活動，由 SQL trigger 保護並行建立、編輯與重新開放。結束／取消不可重開。可更新有效活動，但容量不可小於有效報名人數；修改時間必須同步檢查截止。
- 發布名稱、內容、時間、地點、收費說明及主辦名稱給登入會員；不公開私人聯絡人、電話或電子郵件。收費僅說明，不收款、不贈點、不扣點。私人行程語音沿用原流程，額外活動設定由確認頁填寫。
- 報名唯一(event_id, member_id)，額滿／截止／取消／結束不可新增或重新報名。重送已有效的報名不產生新紀錄；未核銷可取消。
- 主辦名單仅本場主辦可讀，姓名與報名時間／狀態，最新報名置頂；保留取消紀錄。
- QR 使用 32-byte 隨機票證；僅存 SHA256 雜湊，五分鐘有效，重新產生使舊碼失效。本場主辦於開始至結束期間才可核銷；重掃不重複核銷。過期、錯場、非主辦、取消報名／活動不得核銷。
- 所有讀寫有實際 token 驗證及 no-store；未登入／切帳號／離開後的舊回應不得顯示或自動發布。
- 報名連結僅含事件 UUID，完成既有登入後開明細，不自動報名；不接管分享、認領、官方活動等混合路由。
- 關閉、返回、取消始終可達；QR 計時、請求及鏡頭於關閉／離頁釋放。相機解析在本機，不上傳影像。
- 回復：關閉入口／回復此版 Worker 與 Pages 即停止新操作；保留新增表與報名資料，不刪除。
