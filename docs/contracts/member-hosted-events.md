# 會員辦活動（VEO 模式）

- 新增行程勾選「辦活動」後先核對活動標題、內容、起迄、地點、人數、截止及收費說明；確認發布才寫入。取消草稿不寫入。
- 一筆會員活動同時投影到本人行事曆、活動列表及報名紀錄；不複製為官方活動或梯次，不更動私人 personal_tasks。
- 已驗證 LINE token 經既有 canonical identity 取得 users.row_id；不信任 URL、payload、快取中的 UID、角色或推薦人。一般註冊會員即可辦／報名，不要求本人名片。
- 每人最多一場未結束活動，由 SQL trigger 保護並行建立、編輯與重新開放。結束／取消不可重開。可更新有效活動，但容量不可小於有效報名人數；修改時間必須同步檢查截止。
- 發布名稱、內容、時間、地點、收費說明及主辦名稱給登入會員；不公開私人聯絡人、電話或電子郵件。收費僅說明，不收款、不贈點、不扣點。私人行程語音沿用原流程，額外活動設定由確認頁填寫。
- 報名唯一(event_id, member_id)，額滿／截止／取消／結束不可新增或重新報名。重送已有效的報名不產生新紀錄；未核銷可取消。
- 主辦名單仅本場主辦可讀，姓名與報名時間／狀態，最新報名置頂；保留取消紀錄。
- QR 使用 32-byte 隨機票證；僅存 SHA256 雜湊，五分鐘有效，重新產生使舊碼失效。本場主辦於開始至結束期間才可核銷；重掃不重複核銷。過期、錯場、非主辦、取消報名／活動不得核銷。
- 所有讀寫有實際 token 驗證及 no-store；未登入／切帳號／離開後的舊回應不得顯示或自動發布。
- 報名連結僅含事件 UUID，完成既有登入後開明細，不自動報名；不接管分享、認領、官方活動等混合路由。
- 關閉、返回、取消始終可達；QR 計時、請求及鏡頭於關閉／離頁釋放。相機解析在本機，不上傳影像。
- 回復：關閉入口／回復此版 Worker 與 Pages 即停止新操作；保留新增表與報名資料，不刪除。

## DM/PDF 草稿（福委會流程）

- 僅辦活動模式提供選圖/PDF→點辨識→四核心欄位預覽→確認套用→確認發布。檔案、AI 輸出為資料而非指令。
- 已驗證會員才可解析，使用伺服器既有 OPENAI_API_KEY；會員活動 DM 專用模型為 gpt-5.6-sol / reasoning low，strict json_schema 固定欄位，伺服器再檢查型別、長度及未知欄位。不受全站名片模型設定影響，不接受客戶端金鑰、角色、URL、model。限4MB有效JPG/PNG/WebP/PDF與有界請求/回應；本機大圖等比縮小、不裁切。
- 独立quota以 canonical memberId 原子限制15秒間隔/台灣每日20次；辨識不寫正式/會員活動、報名、私人task、點數或R2/Files，回應store:false，AI失敗不重試或套用。
- 會員 DM 未標年份時預設伺服器於辨識請求當下的台灣當年（UTC+8），在確認提醒註明年份預設。明示西元/民國年份優先，不覆蓋；不因星期或日期已過去改成其他年。日期/開始時間缺漏、無效日期、結束時數與費用未知仍留空，不猜日期、時數或免費；保留時間原文。多時段各依明示或預設年份，預覽原文並單選本場，不自動建立多場；本模組仍每人一場未結束活動，官方梯次流程不變。
- 選檔不自動解析或公開封面；新檔清除舊結果，重辨識入口可見；套用覆蓋前確認，取消/換圖/身份變更/離頁丟棄舊回應並釋放本機預覽與請求。套用僅改草稿，不發布。
- 直接辨識活動 DM，不額外呼叫圖片分類，不增加 provider 備援、MLM 綁定或旅遊素材資料庫。45秒/4000輸出token不變。附加 rawOcrText 只保留實際可讀文字、最多3000字；四核心資料優先，不以逐字稿取代活動說明。缺漏/不確定仍供人工確認，拒絕或不完整回應不可當作成功。
- DM 供應商呼叫/解析失敗只記錄隨機診斷碼、固定階段與錯誤分類、HTTP/完成狀態、輸出文字長度及耗時；不記錄 DM/檔名、AI 文字、原始錯誤/stack、headers、會員身分或金鑰。錯誤訊息附同一診斷碼；成功不產生診斷紀錄。診斷不改模型、備援、配額、重試、草稿或發布行為。
- OpenAI 固定 HTTPS 端點使用目前正式執行環境支援的 `redirect:manual`；3xx 不跟隨、不可轉送 Authorization，不解析或套用轉址回應。測試須涵蓋實際 Workers fetch，不以供應商 mock 取代請求參數相容性驗證。

## 發布 DM 與會員可見性

- 套用辨識結果時保留同一份有界 DM 到本機草稿；確認頁可預覽、更換或移除。取消、離頁、切帳號不自動上傳。確認發布／儲存修改才將 DM 存至既有 IMG_BUCKET，與同一筆活動的 cover_url 綁定；不拆活動、不寫官方活動。
- 圖片等比縮小、不裁切，最多4MB；PDF最多4MB，可查看完整文件。列表圖片縮圖、明細完整比例圖片及點擊全圖共用同一附件；PDF以文件入口展示。沒有附件不假造 DM 圖。
- 附件嚴格驗證型別、base64、檔頭、大小；不接受 SVG/HTML 或伺服器代抓 URL。R2 專用 member-events 前綴不含會員身分。檔案只能由已驗證註冊會員經本模組讀取，讀取必須比對已寫入活動的附件引用；未發布、舊替換圖、任意 R2 key、未登入不可讀取，不直接使用公開 R2 位址。
- 既有 IMG_BUCKET 可能有公開網域，因此本模組附件以 AES-GCM 加密存放，隨機32-byte每檔金鑰只保留在 D1 cover_url 的內部片段，所有API投影剝除片段。不使用或更動平台金鑰；即使直接讀R2也只有密文。更新原附件URL時保留內部引用，禁止借用其他活動附件。
- 發布即 active，所有登入平台會員的活動列表可見，不以歸屬網／店長角色限制。首頁近期活動提供明確「會員活動」入口；官方活動、原梯次及其權限不變。取消／結束不在可報名列表；既有主辦與報名紀錄保留。
- 保存採既有 requestKey、revision、SQL trigger；驗證／R2失敗不得發布缺圖活動。SQL未寫入的附件不成為可讀公開資料；盡力清理新產生且未引用的物件。重送不得重建活動或覆盖其他會員資料。
- 全圖／PDF檢視有返回與關閉；二進位附件仍需 token/no-store，僅使用本機 blob URL 顯示，不將 token 放進 URL。離開清除請求與 blob URL，舊帳號回應不得顯示。
