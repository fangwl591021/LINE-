# 會員打卡的監控顯示

- 母站保有打卡、點數及原文字回覆權責；監控修復不得呼叫或重送打卡、扣贈點、LINE訊息或母站webhook。
- 已有checkin_mall_cards的accepted代表LINEAPI接受請求，不代表已讀或確定送達。監控以唯讀投影補顯卡片發送紀錄，固定CHECKIN_MALL:<cardId>識別；如已有同ID真實聊天紀錄，保留真實紀錄並去重。
- 只有相同收件LINEUID對應的user聊天室可看到其卡片紀錄；不得依姓名或任意呼叫者UID合併資料。沿用平台監控管理權限，前端不能擴大可見範圍。
- 卡片摘要使用當次儲存的餘額、時間與狀態，不重新查錢包、不推算贈點成功、不重建母站原文。標示資料來源及母站原文未取得，不把外部不可觀測回覆記成已送達。
- 合併實際聊天及卡片紀錄後依可信時間穩定排序並保留最新80筆。查詢缺少輔助表時保留原監控；不把failed/unknown當已接受。
- 顯示計數可包含虛擬紀錄，但資料庫message_count、未讀、客服狀態、備註、商機、點數和原訊息都不因讀取而異動。
- 對話更新僅在登入管理員可見頁面進行，保留未儲存草稿、內部備註、商機輸入、選取聊天室及使用者閱讀位置；換token/role/thread或離頁時，遲到回覆不能覆蓋當前畫面。
- 監控卡片按鈕僅供預覽，不自動進入商城或紀錄點擊。不得直接執行任意FlexHTML/URL/腳本，數字與文字都須驗證或跳脫。
