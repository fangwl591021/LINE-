# 店家／商品上架政策關卡

- 本人 store/product、admin/catalog、admin/products 及合作店家 save 的 active 公開寫入均必須審核正規化後的本次內容。草稿、下架、封存與既有唯讀目錄不呼叫 AI，不批次變更旧狀態。
- 僅用後端現有 OpenAI key；只送待公開展示文案與圖片，不送 LINE token、會員 UID、點數、聯絡人、訂單、付款或原始資料庫物件。
- 沿用 OPENAI_VISION_MODEL／OPENAI_MODEL；未設定時與 store-ai-draft 一樣使用 gpt-4.1-mini API 型號。審核故障提供 LR 診斷碼，日誌僅記階段／安全代碼／上游 HTTP 狀態，不記原圖、文案、UID 或秘密。
- 待審資料及圖片文字不可信，不得成為模型指令；無工具／不瀏覽任意內容中的網址。圖片先有界安全讀取與型別驗證，只有實際圖片完成審核才可放行。
- 平台禁類：八大／陪侍、詐騙、菸／電子菸／酒、醫療用品／藥品／醫材、犯罪（毒品／非法武器／偽造／人頭帳戶）、色情／性交易、賭博。一般旅馆、理髮、美容、咖啡、非醫療日用品不可只因相似詞自動拒絕。
- allow 必須格式完整、所有政策項目已檢查、沒有問題，且所有提供的圖片已檢查。reject 需具體欄位與原文證據／圖片可見內容；無證據、服務失敗、refusal、JSON／完成度錯誤均不放行。
- 拒絕／manual／error 返回不同代碼與安全原因，原目錄資料完全不改；可明確保存草稿或請管理員核對修改後重新送審。不提供管理員直接免審批准或把服務失敗當作違規的入口。
- 0058 保存 scoped content SHA-256、政策版本、判斷與原因；相同文字及相同圖片位元組可短效重用通過結果，最多 24 小時，修改即失效。前端傳入 pass/hash/review 不作授權。
- 每個 authenticated actor 每日最多 60 次新審查、間隔 3 秒；快取／草稿／未授權／非法與衝突請求不浪費審查。DB 寫入／審核記錄失敗不得公開。
- 審核不證明商家身分、公司所有權、療效或安全性，不影響既有 CAS、role、owner、件數、價格／折抵與稽核原子性。圖片遠端日後替換與 AI 漏判仍需投訴／人工治理，不能承諾百分之百攔截。
