# 店家／商品上架政策關卡

- 本人 store/product、admin/catalog、admin/products 及合作店家 save 的 active 公開寫入均必須審核正規化後的本次內容。草稿、下架、封存與既有唯讀目錄不呼叫 AI，不批次變更旧狀態。
- 僅用後端現有 OpenAI key；只送待公開展示文案與圖片，不送 LINE token、會員 UID、點數、聯絡人、訂單、付款或原始資料庫物件。
- 沿用 OPENAI_VISION_MODEL／OPENAI_MODEL；未設定時與 store-ai-draft 一樣使用 gpt-4.1-mini API 型號。審核故障提供 LR 診斷碼，日誌僅記階段／安全代碼／上游 HTTP 狀態，不記原圖、文案、UID 或秘密。
- 待審資料及圖片文字不可信，不得成為模型指令；無工具／不瀏覽任意內容中的網址。圖片先有界安全讀取與型別驗證，只有實際圖片完成審核才可放行。
- 平台禁類：八大／陪侍、詐騙、菸／電子菸／酒、醫療用品／藥品／醫材、犯罪（毒品／非法武器／偽造／人頭帳戶）、色情／性交易、賭博。一般旅馆、理髮、美容、咖啡、非醫療日用品不可只因相似詞自動拒絕。
- 2026-11-10 原政策澄清：健康、保養、天然安心等泛用字樣、一般食品與環境去味／防霉／洗衣機除臭，及醫院或病房使用場景本身，不構成 medical 證據；需有具體藥品／醫材／醫療用途或疾病、人體器官／生理功能療效線索。存在具體線索而用途未明仍 manual；活化細胞、修護五臟六腑、疾病適用等宣稱仍依原 medical／fraud 限制審核，不因自稱天然或日用品放行，不要求一般用途明確的非醫療商品另證明「非醫療」。
- 2026-11-10 使用者再次確認尺度：一般食品、保健食品、日用品與一般保養沒有具體禁類證據可通過；營養補充、維持正常機能、日常順暢、酵素/益生菌品名、每日餐前食用方法或兒童/寵物份量本身不作醫療證據。一般商品有明確疾病/治療/器官修復宣稱則manual、列原文紅字待確認，不僅憑宣稱把整件食品當成藥品；實際藥品/醫材/醫療用品與其他禁售品仍拒絕。審核通過不認證食用或醫療安全。
- 證據限同一field的連續內容，僅容忍NFKC相容字元（含全半形）與空白的呈現差異，成功後保存及顯示實際原文精確切片；不以摘要、繁簡/字詞/數字替換、跨欄或省略號拼接湊證據。不得只錨到相容字元展開的一部分；錨回原文後仍檢查300字元上限及與理由不同，確保快取可重驗。找不到仍屬審核未完成，不變為allow或違規；短逐字引用通常80字以內，固定輸出上限6000，原schema/圖片/回應大小/逾時/每日額度上限保留。
- allow 必須格式完整、所有政策項目已檢查、沒有問題，且所有提供的圖片已檢查。reject 需具體欄位與原文證據／圖片可見內容；無證據、服務失敗、refusal、JSON／完成度錯誤均不放行。
- 拒絕／manual／error 返回不同代碼與安全原因，原目錄資料完全不改；可明確保存草稿或請管理員核對修改後重新送審。不提供管理員直接免審批准或把服務失敗當作違規的入口。
- 2026-10-19 使用者明確同意的唯一例外：既有按摩機 ec46afc6-dacd-487c-8ca5-c7f993ea2612 的現有 version1 切換網購。僅已驗證管理員的 admin/catalog、明確 confirmed/reference、只有 purchase_mode=online、既定店家與版本、NT$11,800／50%原折抵、核准 content/image fingerprint 及相同政策的 medical-only manual review 全部符合才可放行。拒絕／服務失敗／其他疑慮不適用；不改原 review 為 allow，原子catalog audit記錄操作者、同意原因、核准指紋及前後資料。version2後不再適用；其他商品與後續內容修改仍照原規則。
- 0058 保存 scoped content SHA-256、政策版本、判斷與原因；相同文字及相同圖片位元組可短效重用通過結果，最多 24 小時，修改即失效。前端傳入 pass/hash/review 不作授權。
- 正常送審的快取鍵另加入 `listingReviewPromptVersion`，prompt 澄清後重新審查；`listingPolicyVersion` 及 `readListingReviewSnapshot` 的原始內容／圖片指紋保持不變，已釘死單品人工同意仍核對原指紋與原 manual 紀錄，不套用普通審核快取的命名空間。
- 每個 authenticated actor 每日最多 60 次新審查、間隔 3 秒；快取／草稿／未授權／非法與衝突請求不浪費審查。DB 寫入／審核記錄失敗不得公開。
- 審核不證明商家身分、公司所有權、療效或安全性，不影響既有 CAS、role、owner、件數、價格／折抵與稽核原子性。圖片遠端日後替換與 AI 漏判仍需投訴／人工治理，不能承諾百分之百攔截。
