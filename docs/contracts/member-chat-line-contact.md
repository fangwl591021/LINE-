# 私訊 LINE 加好友與通知契約

- 「LINE通知」沿用既有本人 opt-in、LINE 登入 UID、官方帳號好友確認與背景通知佇列。私人 LINE ID／網址不可成為 push 收件人，也不可自動開啟通知。
- 「（點我新增）」POP 讓本人填寫供聊天對方加好友的 LINE ID／加好友網址。儲存前驗證，空白儲存可移除；不修改會員、名片或點數資料。
- 僅在既有 member_chat_preferences 加入 line_contact_url。只允許本人寫入；對方讀取須為同一對話參與者且雙方未封鎖。不將網址加入找會員、訊息輪詢、公開名片或通知內容。
- HTTPS 限 LINE 加好友網址的明確主機及路徑；不接受任意外部網址、腳本、認證資訊或 UID 冒充 LINE ID。不自動開啟連結、加好友或傳送訊息。
- 開啟通知後，新未讀私訊由官方帳號背景提醒，通常 30–90 秒，同一對話每 5 分鐘時段合併。不保證手機一定彈出橫幅：仍需加入官方帳號、解除封鎖及允許 LINE／系統通知。
- 回歸涵蓋 URL 驗證、本人權限、第三方隔離、封鎖、儲存失敗與重試、通知收件身分不變、關閉收件頁仍觸發合成 push；不傳送正式會員測試訊息。
