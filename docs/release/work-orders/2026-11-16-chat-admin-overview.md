# 聊天室營運儀表板

- 需求：比照櫻花福委會聊天室「儀表板」，呈現點數通營運摘要與操作入口。
- 起點：以 2026-11-16 正式 Worker 發布前相符來源為候選，部署前仍須讀回核對現行版本及綁定。
- 範圍：擴充既有精準指令，總管首屏使用後台相同統計口徑、提供後台入口；保留原商城摘要、店家範圍及會員打卡設定。
- 不變：LINE 簽章、單次回覆所有權、母站路由、身分與角色、購物金／帳本、交易、資料表及資源綁定。
- 驗證：修改前 guard 通過；測試總管／店家／無權限、未知及重複身分、群組、standby、獨立查詢故障與混合事件。不得發送真人測試訊息或修改正式業務資料。
- 發布：完成測試後依正式版本、Worker 綁定與部署結果讀回核對；不得用公開來源覆蓋私有獎金／傭金修正。
