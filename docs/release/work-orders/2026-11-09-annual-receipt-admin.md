# 獎金制度確認年費收款
從 f2fc5f6 修正管理員按「確認收款」時因本人曾移轉 LINE 身分而被阻擋的問題。
範圍為已驗證管理員對現行獨立收款流程的收款登錄；保留訂單金額、身分、角色及交易時檢查。以隔離資料驗證建單、收款、重送、舊身分、撤權及獎金仍待核。
依既有流程跑 guard、部署預演、CI 與正式 Worker 版本核對。
隔離驗證結果：舊版重現移轉提示；新版 37 項相關測試通過。以部署預演產物搭配本機 Worker、D1 與 KV 呼叫後台實際使用的 mlmCreateOrder、mlmMarkOrderPaid，收款再重送後仍為 paid、review_required，推薦人空白、獎金流水零筆。
