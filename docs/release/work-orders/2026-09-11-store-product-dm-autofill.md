# DM 帶入完整性修正

- 使用者回報：OCR 已列出漂浮檸檬茶買2送1/共3盒/特價600，但表單空白且售價未確認。
- 基線：LINE- main 355ce1c；開始時工作樹乾淨。此次未授權提交或部署。
- 根因：單一候選仍需人工按帶入；選擇公開圖片後原本等圖片成功才填文字；prompt 將售價限制為單件而不明確接受整組販售。
- 修正：空白表單且單一候選直接填 title/description/price/category，收合來源預覽。已有手填（含辨識等待期間新增）仍保留並要求替換確認。
- 組合規則：明確3盒組600元是1組600元，不除成單盒200、不採原價900。名稱與說明保留3盒/5入/買2送1等單位條件；真正不明價格仍 null，前端必填。
- 文字先帶入本機草稿，圖片另依勾選同意公開後按鈕上傳；失敗保留文字與原圖片網址，可重試。不自動儲存或上架。
- 不更動身份、限流、資料庫、商品銷售方式、折抵/點數、收款開關、名片OCR或 secrets。
- cache versions: entry22, store-shop20, DM2。嵌入與獨立商城入口同步。
