# 網購上架商品的收款設定提醒

- 使用者要求：網購商品上架時檢查網路訂單／收款設定，未完成須紅字提醒。
- 編輯商品選擇「網購＋上架」即背景讀取本人的收款設定；已上架網購商品的管理列表也顯示提醒，儲存後及返回管理頁重新檢查。
- 分別提示設定缺漏、店家未啟用、全站未開放及讀取失敗；完成且啟用時隱藏。限店內、草稿與封存不觸發該商品的提醒。
- 提供網路訂單／收款設定入口，提醒前往前先儲存編輯。僅提示，不攔截上架、不自動儲存收款、不改訂單或點數。
- 使用現有本人授權 GET /v1/store-commerce/settings，不增加公開銀行資料 API；銀行資料不寫入提示、日誌或 localStorage，錯誤只回覆一般訊息。非管理頁不載入設定，不阻塞商品表單。
- 驗證：4 項單元／契約測試；本機瀏覽器測試缺漏、停用、全站關閉、讀取失敗、就緒隱藏、限店內／草稿、儲存後及入口。測試唯一寫入為本機合成商品儲存；未寫入正式資料。
- 使用者後續明確授權提交／部署。發布前重跑完整 change guard 通過；390px 與 1440px 本機瀏覽器驗證通過。此次僅發布前端，不重部署 Worker 或更動資料庫；正式 API 已確認全站網購開關仍開啟，付款僅匯款，線上點數與 LINE Pay 仍關閉。
