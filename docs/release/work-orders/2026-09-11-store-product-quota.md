# 一般會員一件商品與首頁 AI 浮動助理隱藏

- 使用者確認一般會員可建立本人店面、管理一件商品、使用 DM；完成後直接部署，連同上阶段提交 2ea4b1a。
- 店長/管理員不限；一般會員草稿也計入一件，封存後替換。並行新增以原子 SQL 擋住，不刪除或自動下架既有資料。
- 限定變更 catalog：不放寬收款、商家訂單、商品 QR、扣點或其角色檢查；正式 STORE_COMMERCE_ENABLED 保留原值，不新增 migration。
- 前端名額提示、滿額停用新增、商品每頁 100 件按需載入；一般會員不顯示無權使用的交易管理按鈕。
- 首頁浮動 AI 助理暫時隱藏、不建立元件、不預載圖片；個人 AI 與商品 DM 辨識不受影響。
- Node 76 項商城/DM/錢包/紀錄/QR/交易測試通過；完整 change guard 通過。
- 本機合成資料覆蓋一般會員建立店面/新增/封存、無交易管理入口，以及店長 102 件商品的管理/公開分頁。DM 模型回覆使用測試資料，不代表真實圖片 OCR 準確率。
