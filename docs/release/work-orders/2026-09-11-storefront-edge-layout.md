# 商城外框與留白縮減

- 使用者要求取消包框或大幅縮減左右空間，並授權調整完成後直接提交部署。
- 主系統 main 的 16px 邊距與商城 18px 邊距疊加；商城顯示時以 :has 限定解除 main 左右 padding，解除 app、top-nav 的 448px 上限。
- 商城內嵌／獨立頁都使用可用全寬，左右各 8px（有瀏海安全區時保留安全區），底部導覽同寬。
- 手機保留雙欄；寬螢幕以至少 200px 自動分欄，避免解除外框後將少量商品拉成巨大卡片。
- 離開商城便恢復原主系統容器，未變更其他頁面、點數彈窗、後端與交易設定。
- 本機測試以 index.html 同樣的容器 ID 與尺寸重現外框；正式發布以 GitHub Actions 和檔案核對確認。
- 320、390、1024px 檢查皆通過：8px 邊距、內嵌與獨立頁全寬、上下導覽對齊、無橫向溢出，以及離開商城恢复原框；390px 商城互動與點數彈窗回歸亦通過。
