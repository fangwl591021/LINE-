# 消費折抵紀錄獨立彈窗

- 使用者要求直接 POP 載入截圖中的紀錄區，不再進入完整點數錢包。
- 商城「我的消費折抵紀錄」按下後才載入獨立模組與查詢，保留截圖原有點數異動內容（含折抵與贈點），最近 30 筆範圍不變。
- 沿用既有本人 queryUserPoints API，不新增後端，不呼叫 loadPointsWallet、餘額摘要、QR 或收銀機；不寫入或清除錢包快取。
- 固定關閉列、內文獨立捲動、重新整理、連點防重送、切換身分／離頁／關閉忽略晚到回覆；資料使用 textContent，錯誤不偽裝成沒有紀錄。
- 使用者已授權提交、部署；經 main 推送發布 GitHub Pages 前端，不部署 Worker 或改動資料庫。
- 驗證：Change guard before／after、54 項相關 Node 測試及 git diff --check 通過；本機 Chrome 320／390px 合成資料測試確認 30 筆紀錄、單一查詢、不導頁、不改錢包快取、安全文字渲染、捲動及固定關閉列、錯誤重試／空清單、離頁及換帳號忽略回覆。
