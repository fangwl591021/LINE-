- 日期：2026-09-24；起始 commit：1564cb5。

- 預計檔案：worker/member-chat.mjs、js/modules/member-chat.js、私訊 loader 版本、私訊測試／本機預覽、相關規格與本工作單。

## 2. 允許範圍與合約

- 只改私訊會員資格／目錄／開啟對話相同判斷：既有 LINE 會員有有效 self_profile 本人名片即可，不要求公開、AI 體檢、配對池資格，也不因會員電話尚未補齊而排除。
- 不含已封存／已合併名片；收藏／OCR 他人名片不可成為本人名片。
- 保留 LINE token 驗證、唯一帳號解析、本人排除、雙向封鎖與停止新聯絡。
- 目錄只顯示姓名、公司、職稱摘要，不回傳電話、地址、Email、LINE UID 或完整名片；不授權查看私人名片詳情。
- 姓名／英文姓名／會員名稱／公司／職稱皆可搜尋；英文大小寫與一般空格不影響比對。

## 3. 禁止範圍

- 不變更 users/card_contacts 或名片 public/private、AI 審核、公開池與配對資格；不改 UID 歸屬。
- 不改點數、商城、公開宣傳、舊收件匣、推播、migration、正式 bindings/secrets。
