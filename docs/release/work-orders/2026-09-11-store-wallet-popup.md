# 商城點數按鈕改為彈窗

- 使用者要求點擊只 POP 目前點數與點數 QR，不跳完整錢包。
- 商城所有既有 wallet 入口共用延後載入的 store-wallet-popup 模組；原系統的完整錢包不變。
- dialog 只顯示本人餘額、既有 canonical queriedLineUserId QR、關閉；失敗時提示重試，公開未登入只提示登入。
- 沿用 fetchPointWalletData_(true) 進行最新只讀查詢，不採用他人或過期顯示快取。QR 沿用本地 qrcode-generator，四模組白邊，不帶 token。
- 連點單一視窗／請求；關閉或離頁／切帳號不接受遲到回應。關閉還原焦點，支援 Escape、背景點擊。
- 不改任何後端、資料庫、扣點、交易開關或既有收銀掃碼格式。使用者於 2026-09-11 授權提交並發布 GitHub Pages 前端；正式結果以 Actions 與上線檔案核對為準。
- 合成瀏覽器測試涵蓋最新餘額、canonical QR、零餘額、失敗／跨帳號資料、不跳頁、連點、關閉後回應、切帳號、離頁與公開入口。
- 320px、390px Chrome 合成測試與既有商城版面測試均通過；完整合約檢查通過。測試未呼叫正式點數 API，不代表已以真實使用者做交易驗證。
