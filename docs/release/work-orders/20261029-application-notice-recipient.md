# 合作申請通知指定收件人

- 需求：合作申請通知增加使用者指定的楊滄棋 LINE UID；四類申請沿用彙整為一則多頁 Flex 的流程。
- 範圍：通知 runner、排程呼叫、隔離測試與規格。通知僅含申請種類、時間及受原權限保護的連結，不包含合約或個資。
- 禁止：不得修改會員身分映射、管理員或審核權限、點數與正式申請；不得重送過去失敗通知或新增真人測試申請。
- 已讀 `docs/contracts/reward-applications.md`、`docs/rules/core-invariants.md`、功能變更流程及發布驗證技能。`npm run guard:before` 通過。
- 正式環境唯讀確認指定 UID 的舊新身分連結匹配兩筆會員；既有權限解析器拒絕，歷史有四筆取消。額外收件只使用使用者明確指定之原始 UID，不擴大簽約閱讀權。
- 發布條件：通知隔離測試及 `npm run guard:after` 通過；Worker 部署前後核對實際版本、綁定及排程。正式手機實收需另行驗證。
