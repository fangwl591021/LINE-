# 子站商城資料在聊天室呈現

- 使用者要求資料直接在聊天室呈現。將店家專區的商品、業績、訂單查詢從 URI 按鈕改為 message 按鈕；進入店家專區即顯示本人商品摘要。
- 新增唯讀「商城商品」「商城訂單」「商城業績」；商品／訂單每頁 5 筆，上一頁／下一頁直接回聊天室。商品含價格、狀態、銷售方式與折抵設定；訂單含編號、台灣時間、商品摘要、金額、付款與出貨狀態。
- 新增／編輯商品、核帳／出貨仍用既有登入網頁完成，不新增聊天室寫入流程。
- 沿用已驗證 webhook 身分及一對一限制。一般會員僅自己的商品；店長／管理員查詢自己的店家，管理員儀錶板仍可聚合全商城。不查閱或回傳買家姓名、UID、電話、地址或銀行資料。
- 僅修改商城關鍵字模組、測試與文件；無 migrations、交易開關、前端登入或其他母站關鍵字變更。
- 驗證：18 項商城關鍵字測試通過，涵蓋聊天室按鈕、分頁、跨店隔離、角色變更、群組拒絕、資料欄位白名單、錯誤處理及單一回覆權。
- 使用者後續明確授權提交／部署。发布前重跑完整 change guard 通過，Wrangler 4.128.0 dry-run 成功（gzip 224.19 KiB）；正式 D1 無待套用遷移。部署保留正式變數及交易開關；真實 LINE 回覆仍待部署後實機驗收。
