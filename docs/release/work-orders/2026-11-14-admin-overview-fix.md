# 修復後台營運統計

- 需求：修復營運財務報表 `ACTION_POLICY_NOT_FOUND` 與錯誤或空白統計。
- 基準：`4229d57`；先核對正式主分支與 Worker，保留其他未發布工作。
- 僅實作嚴格總管授權的唯讀彙總，及後台顯示、清楚口徑、失敗重試與相關測試。只傳數字，不傳會員名單；不改會員、獎金、交易、點數、角色、合約或結算資料。
- 指標：會員資料列（含未完成資料）、名片資料列、已上架活動主項（不重複計系列子場次）、有效報名紀錄（排除已取消）。不得以有限分頁筆數或無法讀取時假設零代替。
- 既有手機管理頁呼叫的 `getAdminStats` 含營收欄位但尚未實作，本次採獨立統計路由，不提供假營收。原財務圖表及獎金報表佔位不能宣稱已完成。
- 契約：`docs/rules/core-invariants.md`、專案發布與權限規範；`npm run guard:before` 通過。
- 修改後：`npm run guard:after` 通過；8 項後端與前端專項測試、實際後台殼搭配合成登入的 Chrome 切頁／權限／失敗重試通過。正式資料僅唯讀統計，不建立交易。
- 此變更隔離於過去被自動審核拒絕的獎金報表；不重傳被拒的完整後台檔或替代路徑繞過拒絕。
