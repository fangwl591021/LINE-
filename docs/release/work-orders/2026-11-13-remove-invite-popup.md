# 取消好友邀請確認彈窗

- 需求：移除每次進站可能出現的「確認好友邀請／重新確認／繼續進入」阻塞視窗；不需要使用者手動確認即可進入。
- 基準：LINE- main 9dacc7c6fdb7a746ec73934d24795281cbde6ec0；before guard 通過。
- 範圍：僅移除該彈窗及其重試／繼續互動，更新首頁 auth.js 快取版本與 LIFF 路由契約；不變更其他入口、好友 gate 或後台資料。
- 保留：已簽章 challenge、LINE token/UID 核驗、好友引導前單次有界預留、成功時可信推薦歸屬、失敗不採信網址 ref/net；後端好友事件、點數權威、50 點規則及防重不改。
- 失敗界線：邀請核對若因網路或服務故障無法完成，直接進站且不推定邀請成立；本次不保證該筆分享獎勵可發。不得為測試建立真人會員或真人點數。
