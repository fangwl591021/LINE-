# 私人網購人資料 BAR

- 會員註冊彈窗新增預設收合的「網購人資料」，展開才讀取，獨立按鈕儲存。
- 姓名、台灣手機、選填 Email/郵遞區號、縣市、區域、詳細地址；不收身分證字號，不同步公開名片。
- 新增 0037_store_buyer_profiles.sql，只建立私人資料表，不搬移既有會員、訂單或點數。正式發布時須先檢查並套用此 migration。
- GET/POST /v1/store-commerce/buyer-profile：沿用 LINE Bearer 及 users 本人驗證，不接受 payload UID 擴權；明確同意後儲存，版本 CAS 防止舊視窗覆蓋。查詢無資料回 null，未登入拒絕，不受下單開關影響。
- 結帳增加「帶入已儲存網購人資料」。原「收件人同購買人」同步姓名/手機；有帶入私人資料時亦帶入郵寄地址，地址仍可手動修改。超商門市仍依訂單填寫。
- 只讀取本人私人資料，不自動更新會員基本資料、不建立訂單、不開啟線上交易/扣點；訂單仍使用既有確認流程及不可變快照。
- 本機合成資料與模擬登入測試，不在正式站新增私人資料。89 項 Node 測試、完整 change guard、390px/1440px 填寫及結帳帶入測試通過。
- 使用者已授權提交、部署。正式預檢僅 0037 待套用、同名表不存在，Worker dry-run 通過；發布保留環境變數與交易開關，正式驗證只讀取或開關表單，不儲存個資或建立訂單。
