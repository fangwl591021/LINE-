# CRM 登錄已簽契約

入口：共創夥伴契約與獎金核對 → 登錄已簽契約。預設讀取目前會員的共創夥伴手簽紀錄。未簽提示簽署路徑；待審提示 CRM 審核；通過才可查看摘要並確認登錄。紙本獨立收合。

按確認前核對申請編號、簽署帳號、範本版本、原始簽署內容校驗碼與契約推薦人會員編號。只取簽署資料，不帶入掃碼結緣人。確認仍由既有管理員 API 驗證及寫入，沿用原簽署時間，重試沿用同一份申請編號。無須填銀行帳號或文件校驗碼。不改收款、業績認列、權限、Worker 或資料表。

驗證：變更前後 guard 與 partner-contracts-ui 的 Chrome 合成案例（未簽、待審、內容不符、成功登錄及重開防重）。發布目標：GitHub Pages 兩個管理入口與 partner-contracts 模組。
