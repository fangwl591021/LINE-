# 商店管理角色複查與合併提交

- 使用者要求：商店功能只開放管理員、店長，與前階段 DM 完整性修正一同提交。未要求 push 或部署。
- 基線 main 355ce1c，保留前階段全部 DM 修正，沒有混入不相關檔案。
- 商城伺服器白名單：admin/總管、store/店長；排除 tenant/租戶、一般會員、空值與未知角色。
- 舊系統其他模組有將 tenant 正規化為 store 的相容邏輯；此次只限制商城直接讀取 users.role 的資格，不更動全站角色正規化或任何用戶資料。
- 同步商店建立/編輯、商品寫入、DM OCR、業績、收款設定、商家訂單/核帳/出貨/完成，保留本人店面隔離，admin 不可跨店。
- 公開店面及報價/訂單建立的店主資格、商品會員 QR 發行及商品扣抵資格採相同名單。會員仍可瀏覽合格店面、購物、查看本人訂單與點數；不將顧客入口設為商家專用。
- 前端首頁/我的不向一般會員顯示管理入口；UI 僅提示，不能取代每次後端驗證。強行呼叫 API 仍拒絕。
- 未調整通用點數收銀流程/金額/扣點規則、收款啟用開關、資料庫 schema 或 secrets；沒有正式交易或資料刪除。
