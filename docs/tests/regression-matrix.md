# 回歸測試矩陣

本文件列出高風險流程的最低回歸測試。涉及 UID、名片、AI名片夾、LIFF、Webhook、點數與分享的修改，上線前必須至少檢查相關項目。

## 1. 我的名片

| 編號 | 測試項目 | 預期結果 |
| --- | --- | --- |
| MY-01 | 使用者 A 點首頁「我的名片」 | 顯示 A 的本人名片 |
| MY-02 | 使用者 A 輸入關鍵字「我的名片」 | 聊天室推播 A 的靜態名片 |
| MY-03 | 使用者 A 從設定頁進入專屬名片 | 與首頁我的名片為同一張 |
| MY-04 | 使用者 A 不可看到使用者 B 的名片 | 不會錯讀他人資料 |
| MY-05 | 沒有名片的新用戶點我的名片 | 直接進入建立名片流程 |
| MY-06 | 新用戶首次進入首頁 | 不自動跳強制註冊頁 |
| MY-07 | 建立名片後重整 | 仍顯示同一張本人名片 |
| MY-08 | 同一 UID 重複建立 | 不產生第二張本人名片 |

## 2. 名片版本

| 編號 | 測試項目 | 預期結果 |
| --- | --- | --- |
| CV-01 | 編輯標準版封面 | 只更新標準版 |
| CV-02 | 編輯滿版封面 | 不覆蓋標準版 |
| CV-03 | 編輯正方版封面 | 不覆蓋標準版或滿版 |
| CV-04 | 建立影音版 | 不覆蓋任何靜態封面 |
| CV-05 | 關鍵字「我的名片」 | 只推播靜態版 |
| CV-06 | 關鍵字「影音名片」 | 只推播影音版 |
| CV-07 | 從聊天室編輯後儲存版型 | 專屬名片頁同步顯示正確版本 |
| CV-08 | 裁切選 1:1 | 推播與網頁呈現為 1:1 |
| CV-09 | 裁切選 20:13 | 推播與網頁呈現為 20:13 |
| CV-10 | 裁切選 400:600 | 推播與網頁呈現為 400:600 |

## 3. AI名片夾

| 編號 | 測試項目 | 預期結果 |
| --- | --- | --- |
| AF-01 | 使用者 A 掃描一張他人名片 | A 的收錄名單增加 |
| AF-02 | 重整 AI名片夾 | 名片仍存在 |
| AF-03 | 使用者 B 不應看到 A 掃的私有名片 | B 清單不出現 |
| AF-04 | 修改名片歸屬給 B | B 的相關列表正確顯示 |
| AF-05 | 原掃描者紀錄 | `scannedBy` 仍保留 A |
| AF-06 | 掃描自己的名片 | 不建立重複本人名片 |
| AF-07 | 二面名片流程 | 正反面都能上傳並核對 |
| AF-08 | 直式名片 | OCR 不亂碼 |
| AF-09 | 英文名片 | 欄位可正常辨識與儲存 |
| AF-10 | 非名片圖片 | 不建立資料 |

## 4. 歸屬與推薦人

| 編號 | 測試項目 | 預期結果 |
| --- | --- | --- |
| OW-01 | 透過推薦 QR 加入 | 記錄推薦人 UID |
| OW-02 | 透過無推薦來源加入 | 歸 admin 並標記 fallback |
| OW-03 | 手動修改推薦人 UID | 儲存後重整仍保留 |
| OW-04 | 手動修改歸屬網 | 列表依新歸屬顯示 |
| OW-05 | 已綁定名片被他人掃描 | 不搶走綁定權 |
| OW-06 | 後台查名片 | 可看到 ownerUid / scannedBy / boundUid |

## 5. 按鈕與 URL

| 編號 | 測試項目 | 預期結果 |
| --- | --- | --- |
| BT-01 | 輸入手機號碼 | 自動轉為 `tel:` |
| BT-02 | 輸入 Email | 自動轉為 `mailto:` |
| BT-03 | 輸入一般網址 | 必須是 `http://` 或 `https://` |
| BT-04 | 輸入錯誤網址 | 不可儲存並提示 |
| BT-05 | LINE 好友連結 | 可正常開啟 |
| BT-06 | 推播名片 | 按鈕與後台設定一致 |
| BT-07 | 網頁版名片 | 下方按鈕完整顯示 |

## 6. 分享與 LIFF

| 編號 | 測試項目 | 預期結果 |
| --- | --- | --- |
| SF-01 | 首頁 QR 分享 | 使用推薦好友同源分享邏輯 |
| SF-02 | Flex 名片右上分享 | 開啟分享流程，不進錯誤編輯頁 |
| SF-03 | 傳送網址 | 在聊天室直接發送名片 |
| SF-04 | 分享網址 | 開 shareTargetPicker 或等價分享 |
| SF-05 | Web 版網址 | 瀏覽器可開完整名片 |
| SF-06 | LIFF scope 不足 | 提示 scope 問題，不空白 |

## 7. 點數

| 編號 | 測試項目 | 預期結果 |
| --- | --- | --- |
| PT-01 | 母站贈點 | 子站讀得到 |
| PT-02 | 子站簽到贈點 | 母站帳本一致 |
| PT-03 | 發訊 | 扣 10 點 |
| PT-04 | 優惠券 | 扣 10 點 |
| PT-05 | 消費折抵 | 使用手動輸入折抵點數 |
| PT-06 | 點數顯示 | 不出現負數或破版 |
| PT-07 | ledger 查詢 | 可追溯每筆異動 |

## 8. 收件匣與跟進

| 編號 | 測試項目 | 預期結果 |
| --- | --- | --- |
| IN-01 | 有新信件 | 收件匣 icon 變色或閃動 |
| IN-02 | 收件匣預覽名片 | 顯示完整名片而非只有圖片 |
| IN-03 | 有今日跟進 | 跟進 icon 變色或閃動 |

## 9. 新用戶

| 編號 | 測試項目 | 預期結果 |
| --- | --- | --- |
| NU-01 | 新用戶從分享連結進入 | 停在首頁 |
| NU-02 | 新用戶未建立名片 | 我的名片閃動提醒 |
| NU-03 | 新用戶點我的名片 | 直接進建立名片 |
| NU-04 | 新用戶完成建立 | 不產生多張名片 |
| NU-05 | 新用戶加入點數通 | 點數同步至 AI工坊 |

## 10. 上線前最低門檻

每次部署前至少執行：

- MY-01 至 MY-05
- CV-01 至 CV-06
- AF-01 至 AF-05
- OW-01 至 OW-04
- BT-01 至 BT-06
- SF-01 至 SF-05
- PT-03 至 PT-05

若其中任何一項失敗，不應部署正式 Worker。
