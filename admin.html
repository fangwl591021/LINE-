設定 LINE 用戶輸入關鍵字後要回覆文字，或送出可再觸發指定按鈕關鍵字的 Flex Card。

一般子站關鍵字用「獨立回覆」；與母站同關鍵字時用「只附加母站」，避免搶 replyToken。

貼上完整 Flex JSON 時會優先使用；留空則使用下方簡易欄位產生 Flex Card。

按鈕使用 LINE message action，點下後送出「按鈕關鍵字」，可接到既有簽到、名片或其他關鍵字流程。
